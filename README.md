# HostelDesk

HostelDesk is a React + Flask full-stack web application proposed for Hostel 4, IIT Bombay. Release 1 turns room-cleaning requests from a paper-register/WhatsApp workflow into a transparent system for students, workers, supervisors, and the super admin.

The release-1 workflow includes request credits, preferred availability, supervisor-approved worker assignment, ETA/delay visibility, task-specific chat, photo proof, student confirmation/dispute, feedback, audit records, and anonymised monthly analytics.
